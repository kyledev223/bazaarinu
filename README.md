# Bazaar Inu

A Solana launchpad: visitors launch real pump.fun coins on mainnet from their own wallets, and every coin gets a shopfront and a live dashboard on the site. Non-custodial: the server builds and dry-runs transactions, the wallet signs, and the server relays only transactions that match what was prepared.

Deploy guide, environment variables, first-launch checklist and troubleshooting: **[docs/LAUNCH.md](docs/LAUNCH.md)**.

```bash
npm install && npm test && npm run build
```
